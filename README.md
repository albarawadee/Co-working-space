# Smart Vision — Co-working Space (earlier version)

The first version of the Smart Vision study-hall / co-working management app, with MikroTik WiFi access control.

Live: https://smart-vision-system-five.vercel.app

## Stack
React + Vite · Supabase · lucide-react.

## Run
```sh
npm install
npm run dev
```
Supabase keys go in a local `.env` (never committed).

The current system is developed in a separate repository.
